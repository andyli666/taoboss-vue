# 关联营销

## 📌 功能概述

「关联营销」功能帮助您在商品详情页中**智能推荐搭配商品**，通过展示关联商品提升客单价和转化率。支持三种内容制作方式：系统模板、自定义图片、自定义热区，满足不同店铺的个性化需求。

## 🎯 核心价值

| 价值点 | 说明 |
|--------|------|
| **提升客单价** | 通过推荐搭配商品，引导买家购买更多 |
| **灵活制作** | 支持系统模板、自定义图片、自定义热区三种方式 |
| **实时预览** | 制作过程中实时查看效果，所见即所得 |
| **批量发布** | 一次制作，批量发布到多个商品 |

## 📊 利润计算公式
客单价提升 = 关联营销带来的额外成交金额

转化率提升 = 通过关联营销引导的额外订单数

关联营销本身不产生直接收入，但能显著提升店铺的客单价和整体转化率。

## 📋 功能模块

### 1. 系统模板

使用系统预设的精美模板，只需选择模板和推荐商品即可快速生成关联营销。

**操作步骤：**
1. 点击「点此选择模板」选择一个系统模板
2. 点击「添加商品」选择要推荐的商品
3. 拖动表格行可调整商品排序
4. 右侧实时预览效果

### 2. 自定义图片

上传自定义图片，支持为每张图片设置跳转链接，适合已有设计素材的商家。

**功能特点：**
- 支持 jpg/bmp/gif/heic/png/jpeg/webp 格式
- 单张图片尺寸：宽度 620~1500px，高度 < 2000px
- 大小不超过 5MB
- 最多上传 5 张图片
- 支持拖拽排序
- 支持为每张图片设置独立的跳转链接

**操作步骤：**
1. 点击上传区域选择图片（或拖拽上传）
2. 图片上传后自动显示在右侧预览区
3. 点击图片上的「🔗」图标设置跳转链接
4. 拖动图片可调整顺序

### 3. 自定义热区

上传一张图片，在图片上绘制多个可点击区域（热区），每个热区可设置不同的跳转链接。适合制作复杂的活动页面。

**功能特点：**
- 支持 jpg/png 格式
- 图片尺寸：宽度 620~1500px，高度 < 2000px
- 大小不超过 5MB
- 最多支持 15 个热区
- 每个热区可独立设置跳转链接

**操作步骤：**
1. 点击「选择图片」上传背景图
2. 在图片上点击绘制热区（矩形区域）
3. 为每个热区设置跳转链接
4. 右侧预览区查看效果

## 🔧 操作指南

### 1. 创建关联营销活动

1. 进入「营销」→「关联营销」→「新建活动」
2. 填写活动名称（可不填，系统自动生成）
3. 选择活动内容制作方式：
   - **系统模板**：选择模板 → 添加推荐商品
   - **自定义图片**：上传图片 → 设置跳转链接
   - **自定义热区**：上传图片 → 绘制热区 → 设置链接
4. 选择发布位置（置顶/置底）
5. 选择发布范围（选择要投放的商品）
6. 点击「保存并发布」

### 2. 选择发布位置

| 位置 | 说明 |
|------|------|
| **置顶** | 关联营销展示在商品详情描述上方 |
| **置底** | 关联营销展示在商品详情描述下方 |

> 💡 **建议**：选择「置顶」可获得更高曝光率。

### 3. 发布范围

选择要投放关联营销的商品：
- 点击「添加商品」选择商品
- 支持批量选择
- 可随时删除已选商品

### 4. 发布进度

点击「保存并发布」后，系统会显示发布进度：
- 进度条实时更新
- 发布完成后自动关闭弹窗
- 可点击「确定」跳转到活动列表

## 📌 注意事项

| 注意点 | 说明 |
|--------|------|
| **图片尺寸** | 自定义图片和热区图片需符合尺寸要求，超出平台将自动裁剪 |
| **图片格式** | 自定义图片支持多种格式；热区仅支持 jpg/png |
| **热区数量** | 最多 15 个热区，每个热区必须设置链接 |
| **推荐商品数量** | 受模板限制，系统模板有最大行数和每行商品数限制 |
| **发布范围** | 发布范围不能为空，至少选择 1 个商品 |
| **预览效果** | 右侧预览为示意效果，真实效果请以发布后为准 |
