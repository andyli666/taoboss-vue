
# 订单及利润查询与统计

## 📌 功能概述

「订单及利润查询与统计」是淘掌柜的核心财务工具，帮助您**精准核算每一笔订单的利润**，并提供多维度汇总分析。通过整合商品成本、运费成本、其他支出等数据，系统自动计算订单利润，让您对店铺盈利情况一目了然。


## 🎯 核心价值

| 价值点 | 说明 |
|--------|------|
| **精准核算** | 自动关联商品成本、运费、支出流水，利润计算准确无误 |
| **多维度分析** | 支持明细、日汇总、月汇总、年汇总，满足不同场景需求 |
| **成本微调** | 支持手动调整订单成本，应对特殊情况 |
| **特殊标记** | 可标记特殊订单（如*单、补差价），灵活排除统计 |


## 📊 利润计算公式
利润 = 订单金额 + 邮费 - 商品成本 - 运费成本 - 其他支出 - 退款金额 + 微调成本

| 成本项 | 说明 | 数据来源 |
|--------|------|---------|
| **商品成本** | 商品/SKU 的采购成本 | 需到「商品成本配置」页面设置 |
| **运费成本** | 每笔订单的实际运费 | 需到「运费成本配置」页面设置 |
| **其他支出** | 服务费、营销费、保险费等 | 需通过导入支付宝/微信流水获取 |
| **微调成本** | 手动调整金额（正数增加成本，负数减少成本） | 用户手动录入 |


## 📋 功能模块

### 1. 明细（订单利润明细）

查看每笔订单的利润明细，支持筛选和排序。

**筛选条件：**
- 日期范围
- 订单状态（买家已付款、卖家已发货、交易成功、退款成功等）
- 特殊标记（正常订单/特殊订单）
- 订单号精确搜索

**列表字段：**
- 订单号（点击可跳转淘宝订单详情）
- 付款时间、订单状态
- 订单金额、邮费、退款金额
- 商品成本、运费成本、其他支出（点击可查看明细）
- 微调成本、总成本、利润、利润率
- 已收款、未收款

**操作功能：**
- 微调成本：手动调整订单成本
- 取消微调：撤销已做的成本调整
- 标记特殊/取消标记：将订单标记为特殊订单（不计入利润统计）

> 💡 **提示**：「其他支出」金额可点击查看具体明细，方便追溯费用来源。


### 2. 日汇总

按天汇总利润数据，展示每日的订单数、订单金额、各项成本、利润及利润率。

**筛选条件：**
- 日期范围
- 订单状态
- 特殊标记

**操作功能：**
- 点击「查看明细」可下钻到该日的订单明细


### 3. 月汇总

按月汇总利润数据，展示每月的经营状况。

**筛选条件：**
- 月份范围
- 订单状态
- 特殊标记

**操作功能：**
- 点击「查看明细」可下钻到该月的日汇总


### 4. 年汇总

按年汇总利润数据，展示每年的经营状况。

**筛选条件：**
- 年份范围
- 订单状态
- 特殊标记

**操作功能：**
- 点击「查看明细」可下钻到该年的月汇总


## 🔧 操作指南

### 1. 查看订单利润明细

1. 进入「订单及利润查询与统计」页面，默认显示「明细」Tab
2. 选择日期范围、订单状态等筛选条件
3. 点击「查询」按钮，列表展示符合条件的订单
4. 点击订单号可跳转到淘宝订单详情页

### 2. 查看汇总数据

- 点击「日汇总」Tab 查看每日利润汇总
- 点击「月汇总」Tab 查看每月利润汇总
- 点击「年汇总」Tab 查看每年利润汇总
- 点击汇总行中的「查看明细」可逐级下钻查看详情

### 3. 微调成本

1. 在明细列表中，点击目标订单的「微调成本」按钮
2. 输入调整金额（正数增加成本，负数减少成本）
3. 填写备注（可选）
4. 选择「退款取消成本」开关（订单关闭/退款时是否取消此调整）
5. 点击「保存」

### 4. 标记特殊订单

1. 在明细列表中，点击目标订单的「标记特殊」按钮
2. 确认后，该订单将被标记为特殊订单
3. 特殊订单以黄色背景高亮显示，**不计入利润统计**

### 5. 取消特殊标记

- 点击已标记订单的「取消标记」按钮，恢复正常统计


## 📌 注意事项

| 注意点 | 说明 |
|--------|------|
| **利润准确的前提** | 请确保商品成本、运费成本、支出流水均已正确配置 |
| **特殊订单处理** | 标记为特殊订单后，该订单不计入日/月/年汇总统计 |
| **微调成本** | 微调成本仅作为利润计算时的调整项，不影响商品成本配置 |
| **其他支出查看** | 点击「其他支出」金额可查看该订单的各项支出明细 |
