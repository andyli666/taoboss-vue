# 快速入门

欢迎使用淘掌柜！本指南将帮助您在 5 分钟内了解淘掌柜的核心功能，快速上手店铺运营。

## 📊 第一步：设置成本（核心）

利润计算的准确性取决于成本数据的完整性，建议按以下顺序完成配置：

### 1. 设置商品成本

进入「成本」→「商品成本配置」，为您的商品设置采购成本。

- 支持按商品或 SKU 级别设置
- 支持多时间段成本（不同时期采购价不同）
- 支持 Excel 批量导入

> 💡 **提示**：设置完成后，系统会自动重新计算历史订单利润，无需手动操作。

### 2. 设置运费成本

进入「成本」→「运费成本配置」，配置运费获取方式：

| 方式 | 适用场景 |
|------|---------|
| 菜鸟云仓自动导入 | 使用菜鸟云仓发货，导入支付宝流水时自动获取 |
| 快递对账单导入 | 有快递公司对账单，导入系统匹配订单 |
| 按单计费规则 | 无对账单，设置规则后系统自动计算 |

### 3. 导入支出流水

进入「成本」→「支出明细」，导入支付宝或微信支付流水：

- 自动识别服务费、营销费、物流费、保险费等
- 自动关联订单，纳入利润计算

## 📈 第二步：查看利润

成本配置完成后，进入「订单&利润」→「订单及利润查询与统计」：

- **明细**：查看每笔订单的利润详情
- **日汇总**：按天查看利润趋势
- **月汇总**：按月查看经营状况
- **年汇总**：按年查看整体表现

## 🎯 第三步：开始运营

### 1. 关联营销

进入「营销」→「关联营销」，制作关联营销提升客单价：

- **系统模板**：选择模板，添加推荐商品
- **自定义图片**：上传图片，设置跳转链接
- **自定义热区**：绘制热区，制作复杂活动

### 2. 批量修改

进入「工具」→「批量修改」，批量修改商品标题、价格、库存，提升运营效率。

### 3. 定时上下架

进入「工具」→「定时上下架」，设置商品定时上架/下架，自动化运营。

### 4. 上下架时间优化

进入「工具」→「上下架时间优化」，自动将商品调整到流量高峰时段下架，获取更多免费搜索流量。


## ❓ 常见问题

### Q1：为什么利润显示为 0 或负数？

**A**：最常见的原因是成本未配置。请检查：
- 商品成本是否已设置（商品成本配置）
- 运费成本是否已配置（运费成本配置）
- 支出流水是否已导入（支出明细）

### Q2：订单同步后，修改成本会重新计算历史订单吗？

**A**：会。当您修改成本时，系统会自动判断是否需要重新计算历史订单的利润：
- 修改生效日期为**今天或未来**：只影响新订单
- 修改生效日期为**过去日期**：自动重新计算该日期之后的订单

### Q3：特殊订单是什么？

**A**：特殊订单是指*单、补差价等不计入利润统计的订单。您可以在「订单及利润查询与统计」页面手动标记，标记后订单以黄色背景高亮显示，不纳入利润汇总。

### Q4：免费试用期有什么限制？

**A**：免费试用期内，以下功能有限制：
- 关联营销：每次发布最多选择 **10 个**商品
- 其他功能正常使用
